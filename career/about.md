# About

I am a product and software engineer whose work spans embedded systems, Linux, scientific software, platform engineering, and distributed inference.

I currently lead Moreh's Product Team. My work combines product prioritization, technical coordination, release and validation planning, and hands-on software development. My implementation work now focuses on complex software systems, especially a Rust-based AI inference gateway and Kubernetes operators in Go. Component owners keep day-to-day technical ownership, while I coordinate priorities and decisions across the wider product.

## How I got here

I started with microcontroller firmware, inertial sensing, and device communication. At HARDKERNEL, I moved into Linux kernel and board-support work and contributed code that reached upstream projects. I later worked on scientific Python software, research-software integration, cloud infrastructure, and Kubernetes operations. Those stages shaped how I approach distributed-inference products today: I look at the complete path from an interface or model to deployment, operation, validation, and the people responsible for each part.

## How I work

I stay close to implementation while leading. I prefer explicit ownership, evidence-backed decisions, and small changes that can be tested and reviewed. When work crosses components or teams, I try to make the dependencies and decision boundaries clear before implementation begins.
